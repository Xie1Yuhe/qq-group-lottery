## 一、启动

双击 **`启动界面.bat`**，会弹出一个没有地址栏、没有标签页的独立窗口（Edge 的「应用窗口」模式），
看起来就是一个普通的桌面程序。

```powershell
python app.py                 # 默认用独立窗口打开
python app.py --tab           # 改用普通浏览器标签页
python app.py --port 9000     # 换端口（默认 8791，被占用会自动顺延）
python app.py --no-open       # 只起服务，不打开窗口
python app.py --clean-profile # 退出时清掉浏览器临时配置目录
```

服务只监听 `127.0.0.1`，不对外开放；启动时会带一个一次性 token 校验，避免本机其它程序误调接口。

## 二、界面分区

| 区域 | 作用 |
| --- | --- |
| 顶部数据源 | 二选一：**离线记录**（一个文件路径）/ **机器人接口**（群号 + HTTP 地址），可「连接测试」 |
| 顶部抽奖范围 | **活跃群友**（按发言加权）或 **全群成员**（每人等概率），切换会自动保存 |
| 左侧机器人面板 | 显示「未安装 / 未运行 / 未登录 / 已登录：昵称」，可一键**启动机器人**、**扫码登录**、刷新状态（每 3 秒轮询） |
| 左侧消息存档 | 库内条数、历史跨度、同步间隔；可「立即同步」，每 5 分钟自动增量落盘 |
| 中部活跃度预览 | 指标卡 + 横向条形图 + 候选表格，直接看到谁发过言、发了多少、中奖概率多少 |
| 中部参数区 | 统计窗口、中奖人数、最低发言、权重上限、加权开关，改完点「保存设置」写回 `config.json` |
| 右侧排除名单 | 弹窗管理黑名单 / 白名单，可从候选表格或群成员列表点选加入，也可勾选排除群主、管理员 |
| 底部主按钮 | 橙色「一键开跑」：自动选人最多的群 → 保存设置 → 拉取消息 → 统计 → 开奖，**不会往群里发任何消息** |
| 右上角 | ◐ 切换深色 / 浅色主题（选择会记住） |

## 三、一次完整开奖

1. **准备数据源**
   - 有机器人：填 HTTP 地址与群号，点「连接测试」；或直接点左侧「一键启动」+「扫码登录」。
   - 没有机器人：把群消息导出成文件（`json` / `jsonl` / `csv` / `txt` 都行），填到「离线记录」里。
     四种格式的样例在 `data/sample_messages.*`，可以拿来对照。
2. **看活跃度**：中部表格列出窗口内发过言的人、条数与概率；被排除的人会标灰。
3. **调参数**：统计窗口默认 3 天，中奖人数、最低发言、是否加权按需改，点「保存设置」。
4. **开奖**：点「开始抽奖」（或按 <kbd>空格</kbd>），滚动抽取后中奖卡片逐张揭晓，🥇🥈🥉 标注名次。
5. **导出**：CSV / JSON / 中奖海报（2 倍分辨率 PNG，可直接发群）；也可以「复制文案」拿到一段发群文本。

### 想复现同一份名单

中奖结果会带一个**随机种子**。把种子填回侧栏，或命令行加 `--seed`，就能得到完全一样的名单：

```powershell
python run_lottery.py draw -n 3 --seed 2024
```

### 唯一会真的发消息的动作

「发送到群」按钮是唯一会调用 `send_group_msg` 的入口，**必须你自己点**。测试环境下它会被安全锁禁用。

## 四、参数说明（config.json）

```json
{
  "source": "onebot",          // onebot | file
  "group_id": "123456789",
  "days": 3.0,                 // 统计窗口，单位天，支持 0.5 这样的小数
  "pool": "active",            // active = 只算发过言的人；all = 全群成员
  "winners": 1,
  "weighting": true,           // 按发言条数加权
  "weight_cap": 0,             // 单人权重上限，0 = 不限
  "min_messages": 1,           // 窗口内至少发几条才有资格
  "exclude_roles": [],         // 例如 ["owner", "admin"]
  "blacklist": [],             // 永久排除的 QQ 号
  "whitelist": [],
  "seed": null,                // 填数字可复现
  "post_to_group": false
}
```

以 `_` 开头的键会被忽略，所以可以自己加注释。

## 五、常见问题

**Q：抽出来的人不对/太少？**
先看活跃度预览里符合条件的人数。人数少通常是：统计窗口太短、`min_messages` 太高、或者机器人只在线了一小段
时间（拉不到完整历史）。让机器人多在线一会儿再抽。

**Q：能拉到多少历史消息？**
取决于机器人实现。实测 NapCat 单次最多约 1600 条，本工具会自动向前翻页直到窗口覆盖完整。

**Q：`.browser-profile/` 是什么？**
界面窗口的独立浏览器配置目录，删掉后下次启动会重建，不影响数据。

**Q：程序会联网吗？**
只连你自己填的机器人地址（默认 `127.0.0.1:3000`）。没有机器人时用离线文件模式，全程不联网。
